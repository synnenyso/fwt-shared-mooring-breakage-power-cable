# fwt-shared-mooring-breakage-power-cable
Additional data, files and scripts supporting the article "Early-Stage Evaluation of the Consequences of Accidental Line Breakage in Shared Mooring Systems With Suspended Intra-Array Power Cables"

Folder description: 
plot_layouts : files for visualization of intra-array power cable layouts for the system used in the case study in the article. 
fig_intra-array-power-cable-layouts: visualization of all suspended cable topologies (SC) included in the case study. Images are only included for a given location and orientation of the substation cable connection (SCC). All other combinations can be visualized using the script in "plot-layouts".
